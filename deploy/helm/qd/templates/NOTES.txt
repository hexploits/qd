{{- $fullName := include "qd.fullname" . -}}
{{- $port := int .Values.service.ports.sqs -}}
{{- $host := printf "%s.%s.svc.cluster.local" $fullName .Release.Namespace -}}
{{- $endpoint := ternary (printf "http://%s" $host) (printf "http://%s:%d" $host $port) (eq $port 80) -}}
qd {{ .Chart.AppVersion }} is deployed as "{{ $fullName }}" in namespace "{{ .Release.Namespace }}".

1. Point your SQS clients at the service (any AWS SDK / CLI; only the endpoint changes):

     In-cluster endpoint:  {{ $endpoint }}

     # AWS CLI
     aws --endpoint-url {{ $endpoint }} sqs create-queue --queue-name my-queue

     # Python (boto3)
     boto3.client("sqs", endpoint_url="{{ $endpoint }}", region_name="{{ .Values.config.region }}")

     # Environment variable understood by recent AWS SDKs/CLI v2
     AWS_ENDPOINT_URL_SQS={{ $endpoint }}
{{- if .Values.ingress.enabled }}
{{- range .Values.ingress.hosts }}

     Via Ingress:          http{{ if $.Values.ingress.tls }}s{{ end }}://{{ .host }}
{{- end }}
{{- if not .Values.config.publicUrl }}
     NOTE: queue URLs are derived from the request Host header. If clients reach the service
     under several names, set config.publicUrl to the canonical external URL.
{{- end }}
{{- end }}

   From your workstation:
     kubectl -n {{ .Release.Namespace }} port-forward svc/{{ $fullName }} 9324:{{ $port }}
     aws --endpoint-url http://localhost:9324 sqs list-queues

2. Authentication: QD_AUTH_MODE={{ .Values.auth.mode }}.
{{- if eq .Values.auth.mode "none" }}
   Any access key / secret is accepted (clients still need *some* credentials configured).
{{- else }}
   Requests must be SigV4-signed with a key from the credentials file mounted at
   {{ .Values.auth.mountPath }}/{{ include "qd.credentialsSecretKey" . }}.
{{- end }}

3. Database: QD_DATABASE_URL comes from Secret "{{ include "qd.databaseSecretName" . }}", key "{{ include "qd.databaseSecretKey" . }}".
{{- if .Values.postgresql.cnpg.enabled }}
   This Secret is generated by the CloudNativePG operator for Cluster "{{ include "qd.cnpgName" . }}".
   Pods stay in ContainerCreating / Init until the database is ready:
     kubectl -n {{ .Release.Namespace }} get cluster {{ include "qd.cnpgName" . }}
{{- else if and (not .Values.database.existingSecret) (not .Values.database.url) }}

   *** ACTION REQUIRED: no database was configured. Create the Secret the pods are waiting for: ***
     kubectl -n {{ .Release.Namespace }} create secret generic {{ include "qd.databaseSecretName" . }} \
       --from-literal=database-url='postgres://USER:PASSWORD@HOST:5432/qd'
{{- end }}

4. Roles and rollout order: migrations first, then scheduler + server in parallel. No process
   touches the schema until the migrate Job has finished.
{{- if .Values.migrations.enabled }}
     Job         {{ include "qd.roleFullname" (dict "root" . "role" "migrate") | trunc 52 | trimSuffix "-" }}-{{ .Values.migrations.jobNameSuffix | default .Release.Revision }}   (qd migrate)
{{- else }}
     *** migrations.enabled=false: nothing applies the schema. Run `qd migrate` (same image,
         same QD_DATABASE_URL) yourself; scheduler and server pods wait in their `wait-for-schema`
         init container until you do. ***
{{- end }}
     Deployment  {{ include "qd.roleFullname" (dict "root" . "role" "scheduler") }}   (qd scheduler, {{ .Values.scheduler.replicaCount }} replicas: retention, redrive, queue gauges)
     Deployment  {{ $fullName }}   (qd server, the SQS API)
   During upgrades the old pods keep serving while the Job migrates (migrations are backwards
   compatible). Watch it with:
     kubectl -n {{ .Release.Namespace }} get jobs,pods -l app.kubernetes.io/instance={{ .Release.Name }}

5. Health & metrics (admin port {{ .Values.service.ports.admin }}, server and scheduler pods):
   /healthz (liveness), /readyz (readiness), /metrics
     kubectl -n {{ .Release.Namespace }} port-forward svc/{{ $fullName }} 9325:{{ .Values.service.ports.admin }}
     curl localhost:9325/readyz
   Scheduler metrics: svc/{{ include "qd.roleFullname" (dict "root" . "role" "scheduler") }} (port {{ .Values.service.ports.admin }}).
